# DeepSeek V4 故事化六阶段提示词升级实施计划

## 目标

在不改变六阶段输入材料、数据库结构、模型路由和页面结构的前提下，升级六套版本化
用户提示词和系统保护层，让专辑策划与声音稿面向未读听众形成清晰、克制、有故事感的
听觉内容，并专门抑制 DeepSeek V4 的目录复述、清单化、信息堆叠、重复总结和越界扩写。

## 任务 1：用测试锁定六阶段新契约

- 在 `backend/tests/test_prompt_config.py` 断言六个新的系统版本。
- 断言思维导图只负责知识地图，全书知识模块只负责模块，分模块大纲负责逐集选题。
- 断言声音细纲包含中心问题、认知判断、字数预算、故事抓手和材料舍弃规则。
- 断言初稿与终稿包含 DeepSeek V4 防清单化、防扩写、短段落和减法编辑规则。
- 断言 `snapshot()` 与 `preview()` 对细纲、初稿和终稿都追加叙事/非叙事分流。
- 断言细纲分流不要求上一集内容，初稿和终稿只有在已有上一集终稿时才允许具体回顾。
- 先运行定向测试并记录预期失败，再进入实现。

## 任务 2：升级六套默认用户提示词

- 在 `backend/app/prompt_config.py` 重写思维导图模板，强化核心问题、金字塔结构、
  章节关系和未读听众理解顺序。
- 重写全书知识模块模板，只设计知识模块、听众问题和前后承接，不生成逐集标题。
- 重写分模块专辑大纲模板，增加具体异常/冲突/选择切口、听众钩子、唯一中心问题、
  2–4 个递进要点和连续收听动力。
- 重写声音细纲模板，增加听众最终判断、部分认知任务、故事抓手、过渡句、字数预算
  和明确舍弃项。
- 重写声音初稿模板，按“现象—预期—反差—解释—证据—意义”或叙事路径生产完整口播。
- 重写声音终稿模板，只做减法、听觉节奏、准确性和篇幅检查，不重新选题或增补知识。

## 任务 3：升级系统保护层与书籍类型分流

- 提升六个 `system_version`，让新保护规则以不可变系统版本保存。
- 在初稿和终稿保护层加入来源边界、DeepSeek V4 专项禁令和内部自检要求。
- 抽取统一的书籍类型保护规则函数，供 `snapshot()` 与 `preview()` 共用。
- 叙事类强调人物处境、原文明示动机、行动、结果和剧情解读。
- 非叙事类强调问题、机制、证据与现实意义，并允许仅用于解释的明确假设场景。
- 保持旧模板兼容别名、必要占位符、专辑 Markdown 格式和现有结构校验不变。

## 任务 4：定向回归与兼容修复

- 运行 `backend/tests/test_prompt_config.py` 和 `backend/tests/test_prompt_api.py`。
- 运行声音上下文、专辑规划和工作流相关测试，确认输入边界和任务快照不变。
- 检查锁定旧系统版本、旧全局模板和项目覆盖仍能恢复。
- 检查分模块集数约束、字数范围和最多两次修复逻辑不回退。
- 仅针对发现的真实兼容问题做小范围修复。

## 任务 5：发布本机六个新全局版本

- 初始化新的系统提示词版本。
- 读取本机六个活动全局版本和项目绑定，确认预期版本号。
- 以六套新默认用户模板创建新的活动全局版本，保留全部旧全局版本。
- 不清除或重写任何项目级覆盖；项目级覆盖仍优先于新全局版本。
- 不重跑现有专辑、声音或人工终稿。

## 任务 6：本地预览、全量验证与提交

- 使用现有项目预览六个环节，确认材料占位符均已渲染且系统保护区正确分流。
- 确认细纲只含声音框架与模块拆书稿，初稿/终稿继续使用段落级原文。
- 运行后端全量测试。
- 运行前端 ESLint、生产构建和结构测试。
- 运行 Python 编译、`git diff --check`、密钥边界和提交范围检查。
- 更新 `task_plan.md`、`findings.md`、`progress.md` 与 README。
- 提交实现；不发起付费模型生成，除非用户另行要求。
