# 单集字数范围与口播风格约束实施计划

## 目标

把项目级每集字数范围从专辑规划表单贯穿到四个创作阶段，增加可恢复的任务快照、
确定性的字数验收和最多两次自动校正，同时升级提示词使每集围绕一个中心问题展开。

## 任务 1：项目字段、迁移与 API 契约

- 在 `projects` 表和幂等迁移中新增 `episode_word_count_min`、`episode_word_count_max`。
- 扩展项目生成请求模型，校验 300–10000、最少不大于最多。
- 将范围写入项目、运行元数据和项目详情。
- 增加旧数据库迁移、接口校验和运行元数据测试。

## 任务 2：字数统计与校正服务

- 新增纯函数统计汉字、数字和连续英文单词。
- 新增阶段范围验证结果，包含实际值、上下界和偏差。
- 为初稿、终稿增加最多两次校正调用；每次使用当前阶段模型与任务锁定配置。
- 校正提示包含当前文稿、实际字数、目标范围、精确增减量和事实保护规则。
- 两次后仍不合格时抛出可读阶段错误。

## 任务 3：声音上下文与提示词系统保护

- `EpisodeContextBuilder` 增加 `episode_word_count_range`。
- 四阶段允许该占位符；系统保护后缀也使用相同变量渲染。
- 提升四个系统提示词版本，更新默认模板和保护规则。
- 保持项目级旧模板可用，由系统保护后缀兜底。
- 增加模板预览、快照和旧项目级覆盖测试。

## 任务 4：专辑与声音创作规则升级

- 专辑大纲限制每集一个中心问题和 2–4 个递进要点。
- 声音细纲按字数范围规划模块容量和大致篇幅。
- 初稿增加具体问题开场、日常解释、数据意义、短段落、问答和对比规则。
- 终稿允许删除重复、合并同义论据、拆长段，并要求回扣开场问题。
- 在本地数据库创建新的四个全局提示词活动版本，保留旧版本。

## 任务 5：前端输入与审核反馈

- 在专辑生成卡增加最少/最多字数输入，默认 2000/2500。
- 提交前校验范围并发送结构化字段。
- 项目重新打开时恢复已保存配置。
- 终稿编辑区显示当前字数、目标范围和是否合格；人工版本只提示，不自动改写。
- 更新响应式布局与前端结构测试。

## 任务 6：工作流与恢复回归

- 后台项目任务恢复时从运行元数据读取锁定范围。
- 初稿/终稿自动校正通过现有阶段进度回调显示，不新增用户操作阶段。
- 验证批量失败隔离、单条重跑和阶段模型路由不变。
- 验证提示词锁定和服务重启恢复仍使用任务开始时的范围。

## 任务 7：全量验证与提交

- 运行后端全量测试。
- 运行前端 ESLint、生产构建和结构测试。
- 使用本地项目预览四阶段提示词快照，确认范围一致。
- 在不发起未授权付费批量生成的前提下验证页面与 API。
- 检查 `git diff --check`、密钥边界和提交范围。
- 更新持续记录并提交实现。
