# 逐章拆书结构化输出容错实施计划

## 任务 1：Provider 结构化输出契约

- 为模型终止原因增加专用异常。
- OpenAI 兼容拆书与 JSON 修复使用低温度、显式输出上限和 JSON Object 模式。
- 网关不支持 JSON Object 参数时回退一次。
- `finish_reason=length` 明确分类为输出截断。

## 任务 2：逐项校验与部分结果

- 将章节校验改为可收集问题的逐项模式。
- 无效观点不阻止其有效论据和案例保存。
- 章节结构保存校验问题、有效数量和无效数量。
- 增加完全成功、部分成功和来源无效测试。

## 任务 3：数据库与工作流

- 为章节版本增加校验问题和计数字段。
- 保存 `partial` 章节版本及有效知识资产。
- 运行记录保存错误类别、响应长度和终止原因。
- 批次汇总区分成功、部分成功和失败；下游只接受成功版本。

## 任务 4：页面

- 将章节运行显示为“章节任务”。
- 章节卡片显示部分成功状态、有效数量、未通过数量和问题明细。
- 保留单章重跑入口。

## 任务 5：验证与真实试跑

- 完成后端、前端、lint、构建和密钥边界检查。
- 使用当前豆包模型整本重跑《当代中国社会分层》。
- 汇总成功、部分成功、失败和错误类型；按最终确认仅对金句做逐字校验。
- 不自动生成专辑大纲。
