# 段落级证据溯源实施计划

## 目标

在保留一级章节审核和逐章调用的基础上，将原文切成稳定段落块，使每项知识资产独立引用一个或多个片段；专辑按知识资产编排，声音三阶段可确定性取回直接证据和相邻上下文。

## 任务 1：数据库与兼容迁移

- 新增片段集、片段、片段集成员、知识资产来源、章节版本资产、声音资产关联表。
- 为章节版本、知识资产增加片段集和来源方案字段。
- 旧知识资产默认标记为 `legacy_section_source`，不生成伪造来源。
- 保留旧字段和旧项目读取路径，保证现有 SQLite 幂等升级。

## 任务 2：段落切分与片段集服务

- 新建独立证据模块，完成 300–800 字切分、无损拼接校验、稳定索引和章节路径构建。
- 根据已确认章节构建或复用当前片段集；正文变化时保留历史集合。
- 为现有书籍在数据库初始化后无模型地创建当前片段集。
- 增加确定性、边界、无损和版本测试。

## 任务 3：逐章拆书与严格校验

- 将章节模型输入切换为带路径和片段索引的原文块。
- 更新模型 JSON：概念、金句、观点、每条论据、案例分别携带来源数组。
- 严格校验索引范围、来源顺序和提取型文本的原文匹配。
- 章节版本、知识资产和关联在同一事务保存；旧资产只标记失效不删除。
- 更新演示 provider 和章节回归测试。

## 任务 4：专辑与声音上下文

- 专辑提示词改为输出 `knowledge_item_ids`。
- 校验所有章节已完成精确溯源，并按资产生成声音。
- 新增声音与知识资产关联，派生兼容章节来源。
- 上下文构建器按资产汇总直接片段，并加入同标题节点相邻片段作为辅助上下文。
- 保证细纲、初稿和终稿使用同一证据集合。

## 任务 5：API、界面与 Obsidian

- 新增片段详情、知识资产来源和声音证据接口。
- 书籍工作台显示精确溯源状态、来源标签和可展开原文。
- 专辑审核显示知识资产与原文覆盖；审核台区分直接证据和辅助上下文。
- Obsidian 增加片段笔记及片段、知识资产、声音双向链接。

## 任务 6：验证与交付

```bash
cd backend
../.venv/bin/pytest -q
cd ..
npm run lint
npm test
git diff --check
```

- 使用真实数据库完成幂等迁移和片段统计。
- 只选择一个短章节做真实模型最小验证；不自动重跑整本书。
- 检查旧章节版本、旧项目、API Key、原书和 SQLite 均未进入 Git。
- 更新 README、计划记录并提交实现。
