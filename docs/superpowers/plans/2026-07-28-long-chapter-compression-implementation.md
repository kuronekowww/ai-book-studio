# 长章节拆书稿分段压缩实施计划

## 任务 1：分段与来源校验

- 增加 Markdown 内容块分段函数。
- 增加来源标识提取和完整性校验函数。
- 保持原始顺序并处理超长单块。

## 任务 2：递归压缩

- 对普通分段调用章节压缩模型。
- 只在输出截断时递归二分。
- 全书压缩共用 5 路并发上限，合并结果保持原书顺序。
- 整章全部成功后再缓存合并结果。

## 任务 3：接口错误

- 生成思维导图与专辑大纲接口捕获模型生成错误。
- 以 HTTP 400 返回可读错误。
- 思维导图和专辑大纲显式申请长输出上限。
- 专辑大纲按参考结构输出标题、主要内容、章节/子主题索引、知识资产 ID 和对应原文索引，并在审核页展示。

## 任务 4：测试与真实回归

- 覆盖自动分段、递归重试、来源标识缺失和缓存复用。
- 运行后端测试、前端测试、lint 和构建。
- 重跑“专辑 1”，确认生成非空声音目录。
