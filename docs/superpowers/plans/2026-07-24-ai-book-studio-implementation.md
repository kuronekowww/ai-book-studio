# AI Book Studio 实施计划

## 交付策略

采用纵向切片：先让《圆圈正义》走通真实导入和章节确认，再逐步补齐知识拆解、内容项目、声音版本和 Obsidian。所有模型能力同时提供确定性演示实现与真实供应商接口，避免界面和流程依赖密钥才能验证。

## 任务 1：工程骨架

1. 初始化 React + TypeScript + Vite 前端。
2. 创建 FastAPI 后端包、测试目录和本地启动脚本。
3. 建立统一配置、数据目录和 `.env.example`。
4. 添加前后端健康检查。
5. 验证前端构建和后端测试入口。

## 任务 2：数据库与领域实体

1. 建立 SQLAlchemy 模型和 SQLite 初始化。
2. 实现书籍、解析版本、小节、知识资产、项目、声音、产物版本和节点运行实体。
3. 为标题之外的关系使用 UUID。
4. 添加仓储与事务服务。
5. 编写关系、级联和重启持久化测试。

## 任务 3：书籍导入与章节确认

1. 实现 TXT/Markdown 编码和字面量换行规范化。
2. 实现 EPUB 文本和目录解析。
3. 建立 Markdown 标题树。
4. 对缺少标题或超长文章生成语义切分建议。
5. 暴露预览、编辑和确认接口。
6. 用《圆圈正义》锁定 8 个主题与 49 篇文章的回归测试。

## 任务 4：提示词与工作流运行

1. 从六个 YAML 提取提示词和代码处理语义。
2. 定义节点、输入输出契约和提示词版本。
3. 实现可恢复的顺序节点与并行 map。
4. 实现演示供应商和 OpenAI 兼容供应商。
5. 实现结构化输出校验与一次修复。
6. 实现拆书、思维导图、专辑大纲、细纲、初稿和终稿工作流。

## 任务 5：API

1. 书籍上传、列表、详情、删除。
2. 章节预览、修改、确认。
3. 拆书启动、状态和结果。
4. 项目创建、来源选择、专辑大纲确认。
5. 声音生成、版本、证据和指定节点重跑。
6. 运行记录、取消和恢复。
7. 模型配置与 Obsidian 设置。

## 任务 6：前端

1. 应用壳、导航、状态提示和错误边界。
2. 书籍库和上传流程。
3. 章节切分检查器。
4. 书籍知识工作台和思维导图视图。
5. 项目列表和专辑大纲编辑器。
6. 声音工作台、证据抽屉和版本对比。
7. 设置与运行记录。
8. 桌面优先、平板可用的响应式布局。

## 任务 7：Obsidian

1. 实现稳定目录、文件名和 YAML 属性。
2. 渲染书籍主页、原文小节、知识点、案例、金句和思维导图。
3. 渲染项目主页、来源包、专辑大纲和声音稿。
4. 实现系统区块、人工批注保留区块和合并算法。
5. 实现同步清单、内容哈希和幂等测试。

## 任务 8：验收与交付

1. 后端单元测试和工作流测试。
2. 前端构建。
3. 《圆圈正义》导入回归。
4. 演示模型端到端生成。
5. 单条重跑、重启恢复和 Obsidian 重复同步。
6. 写入 README、配置和启动说明。
7. 检查 Git 不含原书、密钥、数据库和运行产物。
8. 提交完整实现。
