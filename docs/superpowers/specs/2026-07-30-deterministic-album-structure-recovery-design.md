# 专辑大纲确定性结构化与失败恢复设计

## 1. 背景

“专辑5”最近一次任务并不是创作失败。15 个知识模块及其 Markdown 专辑大纲全部生成
成功，合并稿也已保存；失败发生在最后的“结构化专辑大纲”阶段。

第 7 集把内容类型写成“深度解读”，而现有结构校验只接受“解读”或“过渡”。该任务
还创建于模块标识自动注入上线之前，因此旧合并稿没有显式 `MODULE` 标识。模型结构化
输出被校验器判定为“专辑第 7 条字段不完整”，导致页面数据没有保存。

## 2. 目标

1. 已完成的规范 Markdown 优先由程序确定性转换，不再依赖模型完成机械格式转换。
2. 接受有限、明确且不改变语义的内容类型同义写法。
3. 模块标识由数据库中的模块产物关系提供，不要求模型重复输出。
4. 无法安全解析时明确失败或使用现有模型结构化兜底，不静默猜测事实。
5. 复用“专辑5”已经保存的 15 个模块输出，无模型恢复为可审核专辑大纲。

## 3. 方案选择

采用“确定性解析优先，模型结构化兜底”。

不采用只放宽最终 JSON 校验：它不能解决旧合并稿缺少模块标识的问题，也继续依赖模型
正确复制字段。

不采用重新调用模型：结构化只是机械转换，重新调用会增加等待、成本和格式漂移风险。

## 4. 确定性解析器

在专辑规划服务中增加纯函数解析器。输入为有顺序的知识模块和每个模块已保存的
Markdown，输出与现有 `album_outline` 结构一致的字典。

### 4.1 条目切分

- 识别 `## 第1集：标题`、`## 1集：标题` 等现有合法标题形式；
- 每个模块可以包含一条或多条声音；
- 最终位置按模块顺序和模块内部顺序连续编号；
- 标题为空、模块没有可识别条目或条目数量不符时明确失败。

### 4.2 字段提取

提取以下字段：

- 标题；
- 听众钩子；
- 核心主题；
- 核心要点；
- 内容类型；
- 来源章节。

字段标签同时兼容普通 Markdown 和仅包裹标签名称的加粗形式，例如
`听众钩子：` 与 `**听众钩子**：`。解析后统一生成：

```text
听众钩子：……
核心主题：……
核心要点：
1. ……
2. ……
```

不改写字段正文，不补充模型没有生成的观点或案例。

### 4.3 内容类型归一

仅接受以下明确别名：

- `解读`、`解读类`、`深度解读`、`深度解读类`、`书籍解读` → `解读`；
- `过渡`、`过渡类`、`过渡声音`、`承上启下` → `过渡`。

去除 Markdown 加粗和首尾空白后再匹配。未知类型继续失败，不使用模糊包含或模型猜测。
叙事类书籍仍只允许归一后的“解读”。

### 4.4 来源与模块标识

- `module_key` 直接取当前模块对象，不读取模型文本；
- `chapter_keys` 从当前声音块中的 `CHAPTER` 标识提取、去重并保持原顺序；
- 所有章节必须存在于全书目录，并且属于当前模块；
- 缺少章节、跨模块章节、知识资产 ID 或段落索引继续失败。

解析结果继续进入现有 `validate_structured_outline()`，统一执行字段、章节、模块、书籍
类型、总集数和允许范围校验。

## 5. 工作流

新任务的结构化阶段按以下顺序运行：

1. 从本轮各模块已保存的 Markdown 产物执行确定性解析；
2. 通过现有结构校验后，保存 `structured_outline` 并进入项目大纲保存；
3. 确定性解析无法识别非标准格式时，才调用现有结构化模型；
4. 模型输出仍失败时，保留明确错误和原模块产物，允许后续恢复。

确定性解析成功时不调用 `album_outline_structure` 或 `json_repair` 模型。

## 6. “专辑5”恢复

修复发布后，对运行 `482b72d16f824da0bb48c6c99dcf2a0b` 执行一次受控恢复：

1. 读取 15 个已成功的 `module_outline` 产物；
2. 按当次 `module_plan` 还原模块顺序、模块键和章节范围；
3. 使用确定性解析器生成并校验 15 条结构化声音；
4. 覆盖该运行中失败的 `structured_outline` 检查点；
5. 保存专辑大纲和 15 条声音；
6. 将结构化、保存及父运行状态更新为成功；
7. 不调用模型，不删除模块 Markdown，不修改其他项目或历史提示词版本。

恢复操作必须可重复：若同一运行已经成功保存，则再次执行不重复创建声音。

## 7. 错误处理

- 缺少模块产物：列出缺失模块，不进入保存；
- 字段缺失：指出模块和声音位置及具体缺失字段；
- 未知内容类型：显示模型原始值；
- 来源章节非法：显示未知或越界章节；
- 数量不符：显示目标、允许范围和实际数量；
- 保存失败：事务回滚，不留下半张专辑；
- 恢复失败：父任务继续保持失败状态，原模块产物不变。

## 8. 测试

- 普通字段标签和加粗字段标签均能解析；
- “深度解读”归一为“解读”；
- 未知类型不被猜测；
- 模块键由模块关系补入；
- 章节去重、未知章节和跨模块章节校验；
- 一个模块多集和 15 模块 15 集的稳定顺序；
- 确定性解析成功时模型调用次数为零；
- 非标准 Markdown 才进入模型兜底；
- 旧运行恢复幂等，不重复创建声音；
- “专辑5”恢复后项目进入专辑大纲审核状态并显示 15 条声音；
- 后端全量测试、前端构建与本机 API 健康检查通过。

## 9. 非目标

- 不放宽事实来源、知识资产或段落索引校验；
- 不支持任意内容类型自由映射；
- 不重新创作、润色或改写已生成的大纲；
- 不重新调用 15 个模块模型；
- 不改变集数预算、模型选择或提示词版本规则。
