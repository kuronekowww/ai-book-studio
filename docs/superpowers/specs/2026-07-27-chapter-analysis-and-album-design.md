# 逐章模型拆书与专辑生成设计规格

日期：2026-07-27

## 目标

修复 EPUB 书籍在章节类型不符合旧筛选条件时“未生成知识资产却被标记为拆书完成”的问题，并把非叙事类拆书升级为可追溯、可并行、可单章重跑的模型工作流。

本次同时打通完整章节拆书稿到思维导图、专辑大纲的事实输入链，并修复上传书籍后缺少已选文件反馈的问题。

## 已知问题

《当代中国社会分层》已成功导入 234 个一至三级章节节点，但 EPUB 解析器把这些节点全部标记为 `theme`。现有拆书流程只选择 `article` 和 `section`，因此实际获得零个输入节点，没有调用模型、没有生成知识资产，却仍把书籍更新为 `analyzed`。

现有章节审核页只显示三级和四级节点，也无法审核这类 EPUB 的真实一至三级目录树。非叙事类拆书仍使用本地句子截取，没有执行用户提供的逐章拆书提示词。

上传控件同样存在状态反馈问题：文件输入没有绑定 React 状态，用户选择文件后，页面文案、图标和导入按钮均不变化。

## 核心原则

1. 一级章节是模型拆书的调用边界，其全部后代标题和正文按原书顺序合并。
2. `content_index` 由服务端根据原文节点确定性生成，模型不得生成、修改或猜测来源 ID。
3. 章节成功结果立即保存，单章失败不阻断其他章节。
4. 完整拆书稿、结构化结果和派生知识卡片均可追溯到具体章节版本。
5. 思维导图和专辑大纲共享同一份完整或逐章压缩后的拆书事实输入。
6. 专辑集数由用户可选指定；未指定时由模型根据内容结构决定。
7. 过渡声音只在模型认为确有必要时增加，不强制生成，也不能用于凑集数。
8. 原书、模型输入快照和访问密钥只保存在本机，不进入 Git。

## 方案选择

采用严格结构化模型输出，并由后端完成校验、稳定索引绑定和可读 Markdown 渲染。

未采用直接生成 Markdown 后再解析的方案，因为标题层级、可选模块和模型格式漂移会使知识卡片派生与失败判定不稳定。也不采用“先生成 Markdown、再调用模型转 JSON”的双模型方案，因为它增加成本、延迟和新的失败点。

思维导图仍直接输出 Markdown；专辑大纲使用严格 JSON。两者共享事实输入并行生成。

## 章节候选与审核

### 完整目录树

章节审核页展示书籍的一、二、三级目录树。每个节点继续使用稳定 UUID 关联，显示标题、层级、类型、正文长度和确认状态。

### 一级章节候选

每个一级节点拥有独立的 `analysis_enabled` 状态，用于决定是否纳入逐章拆书。该状态不复用 `sections.status`，避免章节确认操作覆盖拆书范围。

自动纳入：

- 序言、前言、导言、导论；
- 第一章、第二章等书籍正文一级章节；
- 附录、后记。

自动排除：

- 目录；
- 版权页、出版信息；
- 表格注释、表下注、数据来源说明；
- 无正文或正文过短的异常一级标题。

系统保存自动判断结果和可读排除原因。用户可以在审核页恢复或排除任意一级候选。人工选择优先于自动规则。

### 章节聚合

一次模型调用的输入由一个已启用一级章节及其全部后代节点组成：

1. 一级章节标题与正文；
2. 全部二级标题与正文；
3. 全部三级标题与正文；
4. 严格按原书顺序排列。

每个标题附带服务端生成的稳定 `content_index`。该索引映射到原文节点 ID，不依赖模型自由文本，也不因模型重跑而变化。

## 逐章拆书工作流

### 批次运行

一本书的拆书创建一个父运行，每个启用的一级章节创建一个子运行。最多同时执行五个章节子运行。

单章流程：

1. 组装章节原文和稳定索引；
2. 使用正式非叙事类逐章拆书提示词调用模型；
3. 解析严格 JSON；
4. 校验章节、子主题和来源索引；
5. 在一个数据库事务中保存章节版本、可读 Markdown和知识卡片；
6. 标记该章节运行成功。

一章失败时只记录该子运行的失败阶段和可读错误，其他章节继续执行。成功章节立即可查看。用户可以统一查看失败列表并单独重跑。

只有全部已启用章节存在最新成功版本时，书籍才能进入“拆书完成”。零候选、零成功或部分失败都不能标记完成。

### 模型输出结构

模型返回的内部结构包含：

- 章节标题；
- 章节主题；
- 子主题；
- 子主题来源索引；
- 概念名称与完整定义；
- 金句原文；
- 主要观点原文；
- 论据原文；
- 案例概述与观点关联。

用户提供的任务、Skills、Workflows、注意事项、金句定义、问题引导法和输出要求全部迁入正式提示词。为适配 DeepGate Anthropic，完整输出规范放入 user 消息。

服务端把已验证结构渲染为用户要求的 Markdown 格式。模型不负责输出或回填真实数据库 ID。

### 章节版本

新增版本化章节拆书记录，至少保存：

- `book_id`；
- 一级章节 `root_section_id`；
- 版本号；
- 结构化 JSON；
- 渲染后的完整 Markdown；
- 提示词版本；
- 供应商和模型；
- 本地输入快照；
- 运行状态和时间。

单章重跑创建新版本，不覆盖旧版本。默认下游流程使用各章最新成功版本。

### 派生知识卡片

章节版本成功保存时同步派生：

- 概念定义；
- 金句；
- 主要观点；
- 论据；
- 案例故事。

每张卡片关联章节分析版本和原文节点。重跑只替换新版本对应的模型派生资产，不删除其他章节、历史版本或人工资产。

## 完整拆书稿与压缩

生成思维导图或专辑大纲时，系统按原书顺序汇总各启用章节的最新成功拆书稿。存在失败章节时禁止开始下游生成，并明确列出未完成章节。

若总输入未超过配置阈值，直接使用完整拆书稿。超过阈值时逐章压缩，而不是对全书一次性粗暴摘要。

每章压缩必须保留：

- 章节标题和顺序；
- 全部有效 `content_index`；
- 概念定义；
- 主要观点；
- 关键论据；
- 案例；
- 金句。

压缩结果按章节分析版本缓存。章节未变化时不重复压缩。任何索引丢失、改变或新增都会使压缩失败，禁止继续生成专辑大纲。

## 思维导图生成

用户点击“生成思维导图与专辑大纲”后，思维导图和专辑大纲使用同一份完整或压缩拆书稿并行调用模型。

思维导图遵循用户提供的正式提示词：

- 判断书籍内容性质；
- 使用金字塔结构组织知识；
- 第二层分支标明引用章节；
- 优先使用原书表达；
- 只输出完整 Markdown 思维导图；
- 不输出 Mermaid 或分析过程。

成功结果版本化保存。思维导图失败不删除已成功的专辑大纲，反之亦然；失败项可单独重跑。

## 专辑大纲生成

### 用户输入

生成前提供两个可选字段：

- `album_special_requirements`：多行自由文本，记录专辑大纲的特殊要求；
- `desired_episode_count`：正整数，记录期望集数。

两项均为空时，模型根据拆书稿的知识结构和内容量自行决定集数。特殊要求只影响专辑大纲，不影响思维导图。

期望集数是创作目标，不是破坏来源结构的硬约束。模型无法在保持内容完整和索引可追溯的前提下精确满足时，可以生成不同数量，审核页展示期望值、实际值和差异提示。

### 输出

模型输出严格 JSON：

```json
{
  "album_outline": [
    {
      "title": "声音标题",
      "main_points": "声音主要观点和内容框架",
      "section_identifier": "稳定 content_index",
      "content_type": "解读类"
    }
  ]
}
```

普通声音关联一个有效 `content_index`，同一索引不得被拆分成多条普通声音。模型根据全书主要内容、用户特殊要求和期望集数选择进入专辑的索引；未进入专辑的索引仍保留在完整拆书稿和知识库中。过渡声音可以关联前后两个有效索引。

叙事类书籍只生成解读类声音。非叙事类书籍默认同样生成解读类声音；仅在模型判断两个知识模块之间确有承上启下需要时增加过渡声音。过渡声音不是必需项，不能作为满足期望集数的填充项。

后端校验：

- JSON 结构完整；
- 标题、主要观点和内容类型有效；
- 所有 `section_identifier` 均存在于事实输入；
- 普通声音没有拆分同一索引；
- 实际声音数量与期望数量不同时保留结果并生成可读差异提示；
- 过渡声音引用两个有效索引；
- 模型没有通过虚构索引满足集数。

通过校验后，系统确定性映射 `section_identifier` 到原文节点 ID，并写入现有声音字段：

- `title`；
- `main_points` 写入可编辑的 `content_framework`；
- `content_type`；
- `source_section_ids`。

生成后进入现有专辑大纲审核页，用户可以修改标题、内容框架、内容类型和来源，再确认进入声音生产。

## 页面交互

### 上传书籍

上传控件改为显式 React 状态：

- 未选择文件时显示加号和支持格式；
- 选择后显示勾选状态、文件名、格式和文件大小；
- 提供“重新选择”和“移除”；
- 未选择时禁用“导入并解析”；
- 上传和解析期间显示进度状态并防止重复提交；
- 导入成功后清空选择；
- 导入失败时保留文件以便重试。

支持 EPUB、TXT、Markdown 的既有范围不变。

### 章节审核与拆书进度

页面显示完整一至三级树、一级章节纳入开关和自动排除原因。顶部汇总：

- 纳入章节总数；
- 已完成；
- 生成中；
- 失败；
- 已排除。

失败章节集中展示并支持单章重跑。成功章节可以查看完整拆书稿、历史版本和派生知识卡片。

### 下游生成

“生成思维导图与专辑大纲”区域增加特殊要求和期望集数输入。空值旁显示“留空则由模型根据书籍内容自行决定”。

运行期间分别显示：

- 拆书稿压缩；
- 思维导图；
- 专辑大纲。

一项失败不遮蔽另一项的成功结果。

## 数据与接口

数据层增加或扩展：

- `sections.analysis_enabled` 及自动判断原因；
- 版本化章节拆书表；
- 章节版本与知识卡片的追溯字段；
- 章节压缩缓存；
- 项目的 `album_special_requirements`；
- 项目的可空 `desired_episode_count`。

接口覆盖：

- 保存一级章节拆书范围；
- 启动逐章拆书批次；
- 查询章节级进度；
- 单章重跑；
- 获取章节拆书版本；
- 生成或单独重跑思维导图；
- 生成或单独重跑专辑大纲；
- 保存专辑特殊要求和期望集数。

章节拆书、压缩和下游模型输入快照只保存在本地数据库，不随书籍或声音详情接口返回浏览器。

## 错误处理与幂等性

以下情况在写入正式章节结果前失败：

- 模型返回空内容或非法 JSON；
- 返回未知 `content_index`；
- 章节或子主题缺少必要来源；
- 数据库事务保存失败。

下游生成在以下情况失败：

- 存在未成功的已启用章节；
- 压缩改变或遗漏来源索引；
- 专辑大纲引用不存在的索引；
- 普通声音拆分同一索引；
- 模型通过无意义过渡或虚构来源凑集数。

重复点击同一活动任务返回现有运行，不创建重复批次。页面刷新和服务重启后从数据库恢复运行状态。成功版本使用运行 ID 和版本号防止重复写入。

## 既有数据迁移

《当代中国社会分层》的错误 `analyzed` 状态退回章节审核或待拆书状态，保留已导入的原文、目录树和稳定节点 ID。

数据库升级为所有既有一级节点计算自动纳入状态，但不自动发起付费模型调用。用户审核范围并启动拆书后，系统执行逐章模型流程。

其他已经产生有效知识资产的书籍不删除旧结果。新流程只在用户重新拆书时创建章节版本和新派生资产。

## 测试与验收

### 后端

1. 模拟 EPUB 的一至三级标题可完整聚合。
2. 序言、正文章、附录和后记自动纳入。
3. 目录、版权、表格注释和异常短标题自动排除，且可人工恢复。
4. 零候选或零成功不能标记拆书完成。
5. 最多五章并行，单章失败不阻断其他章节。
6. 成功章节立即保存，失败章节可单独重跑并生成新版本。
7. 结构化结果正确渲染 Markdown 并派生五类知识卡片。
8. 章节重跑不删除其他章节或人工资产。
9. 逐章压缩保留全部来源索引并正确使用缓存。
10. 思维导图与专辑大纲共享事实输入并可独立失败、独立重跑。
11. 专辑特殊要求和期望集数正确传入专辑提示词。
12. 无期望集数时模型自行决定数量。
13. 过渡声音不是必需项，且不能用于凑数。
14. 非法或虚构来源索引使专辑生成失败。

### 前端

1. 选择 EPUB、TXT 或 Markdown 后立即显示文件名、格式和大小。
2. 文件可以移除或重新选择。
3. 未选择文件时导入按钮不可用，失败后文件状态保留。
4. 章节审核页显示完整一至三级目录树和拆书范围开关。
5. 拆书进度、失败列表和单章重跑状态准确。
6. 特殊要求和期望集数可以留空、保存并回显。
7. 实际集数与期望不一致时显示非阻断提示。

### 真实样书

使用《当代中国社会分层》验证：

- 不再出现零知识资产却标记完成；
- 一级章节按原顺序分别调用模型；
- 二、三级标题和正文完整进入对应章节输入；
- 目录和表格注释不产生垃圾调用；
- 成功生成完整章节拆书稿、知识卡片、思维导图和可审核专辑大纲。

验收同时运行后端测试、前端测试、lint、生产构建和小规模 DeepGate 真实请求。真实原书内容和访问密钥不得进入 Git。
