# 版本化提示词配置中心设计

## 背景

当前专辑大纲、声音细纲、声音初稿和声音终稿的提示词写在后端代码中。用户可以选择各环节模型，但无法在网页中查看、修改或按内容项目调整创作提示词。

本次新增左侧“提示词”标签页，支持全局默认与项目级覆盖。用户只编辑各环节的用户提示词模板；系统角色、输出结构、来源校验和工作流安全约束仍由程序维护。

## 目标

1. 左侧导航增加“提示词”标签页。
2. 支持专辑大纲、声音细纲、声音初稿和声音终稿四个可配置环节。
3. 每个环节提供明确、可插入的上下文占位符。
4. 保存时校验必要占位符、未知占位符和模板语法。
5. 支持全局默认与内容项目级覆盖。
6. 每次保存形成不可变历史版本，可恢复任意历史版本或系统默认。
7. 任务启动时锁定实际提示词版本，运行中修改只影响新任务。
8. 生成产物和运行记录能够追溯实际提示词版本。

## 非目标

- 不开放系统提示词、输出 JSON 契约或来源校验规则。
- 不允许创建任意新工作流环节。
- 不提供代码执行、条件表达式、循环或任意模板函数。
- 不把 API Key、模型地址或其他密钥放入提示词配置。
- 不在提示词预览时调用模型。
- 不自动改写已有专辑大纲或声音稿。

## 方案选择

### 方案一：设置表保存四段当前文本

改动较少，但历史版本、项目覆盖、恢复和运行追溯会逐渐变成特殊字段与 JSON 分支，不利于扩展。

### 方案二：版本化模板注册表

建立模板、版本与作用域绑定，运行时解析有效版本并保存快照。数据关系清晰，适合持续修改和未来扩展。

### 方案三：YAML 文件

适合开发者通过 Git 管理，但网页编辑、项目覆盖、历史恢复和本地数据库一致性较差。

采用方案二。

## 配置作用域

每个环节有三层来源：

1. 项目覆盖版本；
2. 当前全局版本；
3. 系统默认模板。

解析顺序为：

```text
项目覆盖版本 → 当前全局版本 → 系统默认模板
```

项目未配置覆盖时不复制全局模板，而是保持继承关系。全局版本更新后，所有未覆盖项目自动使用新版本；已有项目覆盖不受影响。

## 可配置环节

稳定环节键如下：

| 环节键 | 界面名称 | 工作流位置 |
| --- | --- | --- |
| `album_outline` | 专辑大纲 | 合并全部拆书稿后生成专辑目录 |
| `episode_outline` | 声音细纲 | 当前声音框架与关联原文生成细纲 |
| `episode_draft` | 声音初稿 | 声音细纲与关联原文生成初稿 |
| `episode_final` | 声音终稿 | 声音初稿与关联原文完成口语化终稿 |

叙事类和非叙事类共用一个可编辑的声音细纲模板。程序根据书籍类型追加不同的系统角色和受保护结构要求。叙事类可注入人物关系，非叙事类将人物关系占位符替换为“无须提供人物关系”。

## 可编辑与受保护边界

用户只编辑用户提示词主体。以下内容不出现在可编辑文本中：

- 系统角色；
- 合法 JSON 或文本输出格式；
- 字段名称和结构校验；
- 知识资产 ID 与原文索引约束；
- 不得虚构、不得扩展来源范围等真实性要求；
- 批量失败处理和任务恢复规则；
- 模型协议适配要求。

运行时由提示词编译器按以下顺序组成最终消息：

```text
系统角色
  + 用户保存的模板渲染结果
  + 当前环节受保护的输出和来源约束
```

DeepGate 需要把系统要求合并进用户消息时，供应商适配器仍沿用现有合并策略；配置中心不改变模型协议层。

## 占位符语法

统一使用简单变量语法：

```text
{{placeholder_name}}
```

只允许已登记的变量名，不支持属性访问、函数、条件、循环或嵌套模板。占位符替换为纯文本，原文中的花括号不再执行二次渲染。

### 专辑大纲

必要占位符：

- `{{book_analysis}}`：全部成功章节合并后的完整或压缩拆书稿。

可选占位符：

- `{{book_title}}`
- `{{book_author}}`
- `{{book_type}}`
- `{{album_special_requirements}}`
- `{{desired_episode_count}}`

### 声音细纲

必要占位符：

- `{{episode_framework}}`：当前声音在已确认专辑大纲中的内容框架。
- `{{source_text}}`：当前声音关联知识资产对应的原文块与辅助上下文。

可选占位符：

- `{{book_title}}`
- `{{book_author}}`
- `{{episode_title}}`
- `{{character_relationships}}`

### 声音初稿

必要占位符：

- `{{episode_outline}}`：上一步声音细纲。
- `{{source_text}}`：当前声音关联的原文块与辅助上下文。

可选占位符：

- `{{book_title}}`
- `{{book_author}}`
- `{{episode_title}}`
- `{{episode_framework}}`
- `{{previous_episode_final}}`

### 声音终稿

必要占位符：

- `{{episode_draft}}`：上一步声音初稿。
- `{{source_text}}`：当前声音关联的原文块与辅助上下文。

可选占位符：

- `{{book_title}}`
- `{{book_author}}`
- `{{episode_title}}`
- `{{episode_framework}}`
- `{{previous_episode_final}}`

`{{previous_episode_final}}` 在没有上一集终稿时替换为“当前没有可用的上一集终稿”，不造成模板渲染失败。

## 模板校验

保存前由后端执行权威校验：

1. 模板必须是非空文本；
2. 模板长度不得超过 50,000 个字符；
3. 所有必要占位符至少出现一次；
4. 所有占位符必须属于当前环节的允许清单；
5. `{{` 与 `}}` 必须成对，变量名必须完整；
6. 同一必要占位符允许多次出现；
7. 普通单花括号按正文处理。

前端执行同样的即时校验以改善编辑体验，但不能代替后端检查。保存失败时保留本地编辑内容，明确显示缺少或未知的变量。

## 数据模型

### `prompt_templates`

每个可配置环节一条记录：

- `id`
- `stage_key`
- `label`
- `allowed_placeholders_json`
- `required_placeholders_json`
- `active_system_version_id`
- `active_global_version_id`
- `created_at`
- `updated_at`

`stage_key` 唯一。当前系统版本和当前全局用户版本使用独立指针，系统升级不会覆盖或改写用户版本。

### `prompt_versions`

每次保存一条不可变记录：

- `id`
- `template_id`
- `scope`：`system`、`global` 或 `project`
- `project_id`：系统和全局版本为空，项目版本必填
- `version`
- `user_template`
- `system_prompt`：只在系统版本中保存
- `protected_suffix`：只在系统版本中保存
- `system_version`：只在系统版本中保存代码提示词版本号
- `base_system_version_id`：全局或项目版本创建时所基于的系统版本
- `source_version_id`：恢复或复制版本时记录来源
- `created_at`

同一模板、作用域和项目内版本号递增。系统版本由应用迁移按 `stage_key + system_version` 幂等写入，内容不可通过网页修改。恢复用户历史版本会复制历史正文并创建一个新版本，不修改旧记录。

### `prompt_bindings`

记录项目当前启用的覆盖：

- `project_id`
- `template_id`
- `active_version_id`
- `updated_at`

不存在绑定表示跟随全局。取消项目覆盖时删除绑定，不删除项目历史版本。

当前系统版本由 `active_system_version_id` 指向；全局当前用户版本由 `active_global_version_id` 指向。恢复系统默认时只清空全局指针，历史全局版本保留。

运行时始终使用当前系统版本的角色与保护约束，再叠加解析出的全局或项目用户模板。任务启动后同时锁定系统版本 ID 和用户版本 ID，避免系统升级或用户修改导致运行中任务漂移。

### 任务与产物快照

工作流运行元数据增加四个环节的实际 `prompt_version_id` 与系统版本。声音产物继续保存人类可读的 `prompt_version`，并增加可空的 `prompt_version_id`。旧产物保持可读，不回填猜测版本。

渲染后的完整输入继续进入现有运行输入快照；对外项目详情接口不直接下发敏感或超长输入快照。

## 有效提示词解析器

新增独立提示词服务，职责包括：

- 列出模板和占位符元数据；
- 创建并校验全局或项目版本；
- 解析某个项目、某个环节的有效版本；
- 渲染占位符；
- 恢复历史版本；
- 恢复全局系统默认；
- 取消项目覆盖；
- 生成预览数据。

工作流只依赖解析后的不可变 `PromptSnapshot`，不直接查询编辑表。快照包含：

- 环节键；
- 系统版本；
- 用户版本 ID 和版本号；
- 来源类型；
- 用户模板正文；
- 渲染后的用户正文；
- 受保护约束正文。

## 任务锁定规则

- 专辑大纲任务启动时锁定 `album_outline` 快照。
- 批量声音任务启动时一次性锁定 `episode_outline`、`episode_draft` 和 `episode_final` 三个快照，并写入父批次元数据。
- 每条声音按父批次快照顺序生产，批次中途修改提示词不改变未开始的声音。
- 单条重跑启动时重新读取当前有效版本。
- 从声音初稿阶段重跑时仍锁定当前初稿与终稿提示词；已有细纲内容作为输入，不重新使用细纲提示词。
- 任务重启恢复时按保存的版本 ID 重建相同快照，不读取最新配置。
- 被任务引用的提示词版本不可删除。

## 左侧提示词页面

主导航新增：

```text
提示词
```

页面顶部：

- “全局默认 / 项目覆盖”分段选择；
- 项目覆盖模式下的内容项目选择器；
- 当前作用范围和继承状态说明。

页面采用三栏结构：

### 左栏：环节列表

- 专辑大纲；
- 声音细纲；
- 声音初稿；
- 声音终稿；
- 每项显示“系统默认 / 全局 vN / 项目 vN”。

### 中栏：模板编辑器

- 当前环节名称；
- 当前生效来源与版本；
- 大尺寸多行文本编辑器；
- 未保存状态；
- “保存为新版本”；
- “预览填充结果”；
- 离开环节或页面时提示未保存修改。

项目覆盖模式第一次编辑时，以当前有效全局模板作为初始内容；只有保存后才创建项目覆盖。

### 右栏：占位符与版本

- 允许占位符列表；
- 必要和可选标记；
- 中文说明；
- 点击插入光标位置；
- 历史版本列表；
- 查看历史正文；
- 恢复指定历史版本；
- 全局模式提供“恢复系统默认”；
- 项目模式提供“取消项目覆盖”。

恢复和取消操作必须二次确认，因为它们会改变后续任务的有效提示词；历史记录不会删除。

## 预览

预览只执行模板渲染，不调用模型：

- 全局模式使用短小、明确标记的示例数据；
- 项目模式优先使用所选项目的真实书名、当前声音框架和已有阶段结果；
- 预览声音细纲、初稿或终稿时提供声音选择器，默认选择项目第一条声音；
- 项目没有声音或阶段结果时，使用带说明的示例值；
- 长拆书稿和原文块在预览中截断，并显示原始长度；
- 预览明确区分“用户模板渲染结果”和“系统追加的受保护约束”。

## API

新增接口：

- `GET /api/prompts/templates`
  - 返回四个模板、占位符、当前全局版本和系统默认信息。
- `GET /api/prompts/effective?stage=...&project_id=...`
  - 返回当前有效用户模板、来源和版本。
- `GET /api/prompts/history?stage=...&scope=...&project_id=...`
  - 返回版本历史，不返回运行输入快照。
- `POST /api/prompts/versions`
  - 校验并创建全局或项目版本。
- `POST /api/prompts/restore`
  - 从指定历史版本复制并创建新版本。
- `DELETE /api/prompts/global/{stage}`
  - 恢复系统默认，仅清空全局活动指针。
- `DELETE /api/projects/{project_id}/prompts/{stage}`
  - 取消项目覆盖，仅删除活动绑定。
- `POST /api/prompts/preview`
  - 返回渲染预览和受保护约束，不调用模型。

接口只接受四个稳定环节键。项目级操作必须验证项目存在；版本与模板、作用域和项目必须一致。

## 兼容与迁移

1. 数据库启动迁移创建三张表并加入产物版本引用字段。
2. 从现有代码提示词幂等写入四个 `scope=system` 的系统版本，并设置当前系统版本指针。
3. 初次升级时不存在全局和项目用户版本，所有任务行为与当前系统默认保持一致。
4. 现有 `PromptDefinition.version` 成为系统版本，继续显示在旧产物上。
5. 已有产物、项目和批次不自动重生成。
6. 迁移时保留当前四个代码提示词的系统版本 ID。现有运行中任务没有用户版本时按其已有 `prompt_version` 映射到对应系统版本；无法映射时明确失败并保留任务诊断，不静默混入新用户模板。

## 错误处理

- 缺少必要占位符：返回缺失变量列表。
- 未知占位符：返回未知变量列表和当前环节允许清单。
- 花括号不完整：返回具体位置附近的模板片段。
- 模板为空或过长：返回明确长度限制。
- 项目或版本不存在：返回 404。
- 版本与作用域不匹配：返回 409，不自动改绑。
- 预览数据不足：使用标注过的示例值，不报模型错误。
- 保存失败：前端保留未保存正文。
- 运行时找不到已锁定版本：任务失败并记录版本 ID，不静默切换到最新版本。

## 测试

### 数据与服务测试

- 四个系统模板幂等初始化。
- 全局版本递增且历史不可变。
- 项目版本递增且只影响对应项目。
- 有效版本按项目、全局、系统顺序解析。
- 恢复历史创建新版本。
- 恢复系统默认保留历史。
- 取消项目覆盖后重新跟随全局。

### 占位符测试

- 必要占位符完整时保存成功。
- 缺少必要占位符时保存失败。
- 未知占位符和不完整花括号保存失败。
- 可选占位符缺失时保存成功。
- 原文中的花括号不会二次渲染。
- 非叙事书的人物关系得到固定替代文本。
- 无上一集终稿时得到固定替代文本。

### 工作流测试

- 专辑大纲使用项目覆盖或全局版本。
- 声音三个阶段分别使用各自有效版本。
- 批量启动后修改提示词不影响批次快照。
- 单条重跑使用当前有效版本。
- 重启恢复使用保存的版本 ID。
- 产物记录版本 ID、系统版本和渲染输入。
- 旧项目和旧产物保持兼容。

### API 与界面测试

- 左侧出现“提示词”标签页。
- 全局与项目范围切换正确。
- 四个环节显示有效来源。
- 必要和未知占位符即时提示。
- 点击占位符插入光标。
- 保存产生新版本。
- 历史查看与恢复正确。
- 恢复系统默认和取消项目覆盖正确。
- 未保存修改切换时出现提醒。
- 预览不触发模型请求。

### 回归测试

- 章节拆书、思维导图和模型配置不受影响。
- 专辑大纲来源索引校验继续生效。
- 声音细纲、初稿、终稿的上下文链不变。
- 批量最多五条并行与失败继续策略不变。
- 后端全量测试、前端 lint、生产构建和页面结构测试通过。

## 验收标准

1. 左侧“提示词”页面能够编辑四个用户提示词模板。
2. 全局修改会影响所有未覆盖项目，项目覆盖只影响选中的内容项目。
3. 四个环节均显示可插入的中文说明占位符。
4. 缺少必要变量、未知变量或模板语法错误时无法保存。
5. 每次保存创建新版本，历史可查看和恢复。
6. 全局可恢复系统默认，项目可取消覆盖并重新跟随全局。
7. 批量和单条任务使用正确的提示词快照，运行中不会漂移。
8. 产物能够显示并追溯实际提示词版本。
9. 用户不能通过可编辑模板删除输出结构、来源校验和工作流安全约束。
10. 已有项目、专辑、声音稿和模型设置保持不变。
