# 逐章拆书结构化输出容错设计

## 背景

`doubao-seed-2.0-pro` 执行长章节拆书时，大量响应在约 7,000–11,500 字符处出现 JSON 字符串未闭合、缺少分隔符或额外文本。少量合法 JSON 又因模型改写定义、观点或论据，无法通过旧版段落级逐字校验。

当前流程把以上任意一个问题都视为整章失败，因此一条无效知识资产会导致同章其余有效内容无法保存。

## 目标

- 降低长章节 JSON 截断和语法错误概率。
- 明确区分输出截断、JSON 语法错误和原文校验错误。
- 合法知识资产及时保存，单项错误不再拖垮整章。
- 部分成功章节不能静默进入思维导图和专辑大纲。
- 保持一级章节仍是一次主要拆书调用；只允许必要的 JSON 修复调用。

## 模型调用策略

### OpenAI 兼容结构化任务

对 `book_analysis` 和 `json_repair`：

- `temperature` 使用 `0.1`。
- 显式设置足够的输出 token 上限。
- 优先发送 JSON Object 响应格式。
- 如果网关明确拒绝响应格式参数，移除该参数后重试一次。
- 其他自由文本任务保持现有采样参数。

### 终止原因

OpenAI 兼容 provider 读取 `choices[0].finish_reason`：

- `stop`：正常返回文本。
- `length`：抛出专用“模型输出达到长度上限”错误，附带响应字符数。
- 其他非空异常原因：抛出可读错误。

达到长度上限时不进入 JSON 修复，因为缺失的后半部分无法由“只修语法”可靠恢复。

### JSON 修复

- 仅在响应正常结束但 JSON 解析失败时调用一次 `json_repair`。
- 修复输出仍需重新解析和完整校验。
- 第二次失败记录为“JSON 修复失败”，保留原始错误与修复错误摘要。
- 运行记录保存响应字符数、终止原因和错误类别，不保存完整模型响应。

## 逐项来源校验

校验器返回：

- 通过校验的结构化章节内容；
- 未通过项目列表；
- 每项问题的资产类型、显示标题、错误原因和来源索引。

按用户试跑中的最终确认，校验规则为：

- 所有知识资产都必须引用当前章节真实存在的段落级 `content_index`；
- 金句必须能在引用原文块中连续找到，仅忽略空白差异；
- 概念定义、主要观点、每条论据、案例和案例证据允许忠实概括，不做逐字匹配；
- 案例证据索引仍必须包含在案例来源索引内。

无效项目不写入知识资产表。其他有效项目继续生成稳定知识资产 ID 并保存。

如果一个主要观点无效，其下论据和案例仍分别校验；通过校验的论据和案例作为独立知识资产保存，并在章节结构中标记原所属子主题，不伪造主要观点。

## 章节与批次状态

### 成功

- JSON 合法；
- 所有输出项目通过校验；
- 章节版本状态为 `succeeded`；
- 可参与全书思维导图和专辑大纲。

### 部分成功

- JSON 合法；
- 至少一个知识资产通过校验；
- 同时存在未通过项目；
- 章节版本状态为 `partial`;
- 有效资产立即保存；
- 运行记录状态为 `partial_failed`，展示有效数量和问题数量；
- 书籍保持“部分章节已完成”状态。

### 失败

- 输出达到长度上限；
- 原始 JSON 与修复 JSON 均无法解析；
- JSON 合法但没有任何有效知识资产；
- 章节版本不作为可用拆书结果。

批次汇总分别统计成功、部分成功和失败章节。

## 下游保护

- 最新章节查询只接受 `succeeded`。
- 存在 `partial` 或失败章节时，禁止生成全书思维导图和专辑大纲。
- 页面明确提示需重跑的章节和未通过项目。
- 重跑成功后，新版本替代部分版本参与下游；旧版本和问题记录继续保留。

## 页面

- 运行记录将 `chapter_analysis` 显示为“章节任务”，不再显示“声音任务”。
- 错误标签区分：
  - 输出达到长度上限；
  - JSON 语法错误；
  - JSON 修复失败；
  - 原文校验失败；
  - 部分成功。
- 章节卡片显示有效资产数量、未通过数量及问题明细。

## 数据

为章节分析版本增加校验问题 JSON 和有效/无效数量；旧版本默认没有问题。运行记录继续使用现有 `metadata_json` 保存非敏感诊断信息。

不保存完整失败响应，不修改原文片段和知识资产来源模型。

## 验收

- OpenAI 兼容拆书请求使用低温度、输出上限和 JSON Object 模式。
- 网关不支持 JSON Object 参数时可回退。
- `finish_reason=length` 得到明确截断错误且不调用 JSON 修复。
- JSON 语法错误只修复一次。
- 金句不匹配或来源索引无效时，有效资产被保存，章节状态为部分成功。
- 部分成功章节不能生成专辑。
- 重跑成功后可正常进入下游。
- 运行记录正确显示章节任务及错误分类。
- 后端测试、前端测试、lint 和生产构建通过。
