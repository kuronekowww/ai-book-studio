# 示例字幕风格研究与四阶段提示词优化

## 1. 目标

基于六篇经济、资本市场和产业类口播字幕，优化讲书产品的专辑大纲、声音细纲、声音初稿和声音终稿提示词，使生成内容适合此前没有读过原书、主要通过连续收听获取知识的听众。

目标风格定义为“教学型叙事”：

> 用具体问题制造认知缺口，用极简模型建立主干，用案例和因果链解释机制，再补充必要的复杂性，最后回扣听众最初的问题。

本设计只借鉴示例稿的高层讲述方法，不复制任何创作者的口头禅、标志性句式、段子或个人表达。

## 2. 示例文稿的共同写法

### 2.1 宏观结构

六篇稿件的开场通常不是定义或目录，而是以下入口之一：

- 反常识现象，例如纸币被拿去糊墙；
- 与普通人相关的现实问题，例如利率为什么影响房价；
- 巨大数字或强烈对比，例如游戏产业规模与电影、音乐产业的比较；
- 熟悉但没有真正理解的概念，例如上市、对赌协议。

随后会连续提出两到四个问题，向听众承诺本期要建立的认知框架。正文不按资料顺序罗列，而是采用“先简化、再展开、再纠偏”的教学顺序。结尾回到开篇问题，把全篇压缩成一个听众可以复述的判断。

### 2.2 解释方法

1. **先给极简模型。** 利率稿先假设所有利率相同，上市稿用奶茶店解释股份稀释，房地产稿先区分消费品和投资品。
2. **沿因果链推进。** 频繁使用“如果、那么、于是、所以、但是”，让听众知道当前结论如何从前一步推导而来。
3. **抽象概念立即翻译。** 专业术语第一次出现时，紧跟日常语言解释或具体情境。
4. **数据必须解释意义。** 不只报数字，还会说明量级、比较对象以及它为什么值得关注。
5. **案例各司其职。** 虚拟小案例用于解释机制，真实案例用于展示机制如何改变结果。
6. **主动纠正过度简化。** 主干讲清后，再说明例外、不确定性或反方向力量。

### 2.3 语言与节奏

- 句子偏短，一个句子主要承担一个意思；
- 使用问句和第二人称维持共同思考感；
- 使用“我们先看、换句话说、问题来了、再往前一步”等听觉路标；
- 每解释一个抽象概念，尽快跟一个例子、比喻或现实意义；
- 轻微调侃、自嘲和反差只承担认知缓冲，不独立造梗；
- 高信息密度与低理解门槛同时存在，口语化不等于内容变少。

## 3. 现有提示词的差距

| 环节 | 已有优点 | 主要缺口 |
| --- | --- | --- |
| 专辑大纲 | 已包含未读听众、单集问题、因果链与轻松克制 | 需要更明确地设计全专辑难度梯度、认知缺口和相邻集承接 |
| 声音细纲 | 有框架、原文、背景说明和过渡 | 没有要求选定开场入口、极简模型、因果节点、案例职责与纠偏点 |
| 声音初稿 | 以细纲为结构、以原文为事实边界 | 容易把细纲扩写成书面说明文，缺少可执行的解释节奏和听觉导航 |
| 声音终稿 | 强调自然、清晰、适合听觉 | 容易把“口语化”误解为增加语气词，缺少朗读级检查标准 |

关键判断：终稿不得增加初稿未覆盖的新事实，因此讲述结构必须在细纲阶段设计，在初稿阶段写足；终稿只负责听觉化，不能承担结构补救。

## 4. 方案比较

### 方案 A：只强化终稿

改动最小，但无法修复细纲和初稿中已经形成的资料罗列、定义先行或因果断裂。

### 方案 B：四阶段分工优化

专辑大纲负责全局认知路线，声音细纲负责单集教学设计，初稿负责完整解释，终稿负责朗读体验。结构稳定，最适合批量生产。

### 方案 C：每次附带完整范文

单篇风格可能更鲜明，但输入成本高，容易复制示例作者的个人表达，也可能让不同书籍失去自身气质。

采用方案 B。

```text

# 书籍信息
书名：{{book_title}}
作者：{{book_author}}
书籍类型：{{book_type}}

# 用户要求
专辑特殊要求：{{album_special_requirements}}
期望集数：{{desired_episode_count}}

# 总体目标
1. 保留原书最重要的思想、论证、人物、事件和案例，但不要照着章节目录做内容搬运。
2. 为听众建立一条逐步增加理解难度的认知路线：先让人看见问题，再提供必要背景，然后解释原因与机制，最后讨论影响、争议或出路。
3. 每一集只解决一个清楚的问题；相邻两集之间应有知识上的承接，但每集也能独立听懂。
4. 让听众知道这件事为什么与自己已有认知或现实生活有关，而不是只知道“书里讲了什么”。

# 编排方法
第一步：从拆书稿中找出全书最值得回答的核心问题，以及支撑这些问题的关键知识模块。
第二步：判断听众理解每个问题前必须知道什么，把必要背景安排在前，不要求听众自行补课。
第三步：按“现象或故事—问题—原因或机制—影响—判断或启示”组织认知路线；叙事类书籍则按人物目标、关键冲突、事件转折和意义组织。
第四步：检查内容是否重复、跳跃或难度倒置。高度相关的知识可以合并，无关内容不要为了凑集数强行拼接。

# 单集选题标准
1. 标题从具体问题、人物、事件、矛盾、反常识现象或因果悬念切入，准确、有趣但不标题党。
2. 每集明确一个“认知缺口”：听众原本可能怎么理解，听完后会多理解哪一层。
3. 每集的核心要点必须递进，不得只是三条并列摘要。
4. 优先选择能够讲出因果链的观点和案例；数据要有解释价值，不能只承担装饰作用。
5. 不单独生成泛泛的导入、作者生平或内容总结，除非它是理解全书不可替代的背景。

# 讲述气质
轻松但克制，清楚而有推动力。可以用具体情境、反差或轻微幽默降低理解压力，但不能堆梗、滥用网络热词、模仿特定创作者或为了戏剧性夸大原书。

# 全书拆书稿
{{book_analysis}}
```

## 6. 口播样稿

### 标题

城乡分野为何如此顽固：进了城，为什么还不等于成了市民？

### 来源边界

- 观点资产：`knowledge_5dd6901b1ae83b0d9dd198df`
- 案例资产：`knowledge_af3c9c9718b4d5d451a80af9`
- 论据资产：`knowledge_c5ca49ed5acfefe4dd86a1fa`、`knowledge_cfd9f41bd8bb9449b0c42ec3`、`knowledge_8151850702d636a339948b58`
- 金句资产：`knowledge_5ce9a7136e9205c83b86910e`
- 原文块：`content_05ff08770b509d6a8578`、`content_5eaa58c512da25730a7b`

### 正文

一个人在城市里工作、生活，甚至已经待了很多年，他算不算真正的城市人？

这个问题听起来好像没什么悬念。人都进城了，当然就是城市人。可《当代中国社会分层》给出的答案没有这么简单。书中提到，当时有两亿多农民工在城市、城镇工作，却没有真正完成“市民身份”的转换。

于是问题来了：人已经可以流动，为什么身份没有跟着一起流动？很多人会把原因直接归到二十世纪五十年代建立的城乡户籍制度上。这个判断不能说完全错，但它只看到了离我们最近的那一层。

作者李强提醒我们，中国的城乡差异远比现代户籍制度更古老。要理解它，不妨先想象一堵城墙。

古代中国有“国人”和“野人”的区分。“国人”住在城里，“野人”住在城外和乡下。白天，城门可以打开；晚上城门一关，城乡流动也就被切断了。城墙当然有防御作用，但在作者的分析里，它同时保护着城里人的利益。

换句话说，城乡分野一开始就不只是住在哪里的问题。它还关系到资源集中在哪里，哪些人更靠近资源，以及谁更容易被排除在外。

费正清曾把这种结构概括为“两个中国”：一边是人数众多、相对稳定的农民社会；另一边是城市和市镇中更为流动的上层，那里聚集着地主、文人、商人和官吏。这个说法要强调的，不是中国真的被切成两个国家，而是城乡长期处在两套很不一样的生活和资源体系里。

看到这里，我们就能重新理解户籍制度的作用了。它不是凭空创造了城乡差异，更像是在一扇已经存在很久的门上，又加了一把很结实的锁。

从二十世纪五十年代中后期开始，严格户籍制度进一步固化了城乡分野。书中提到，从一九五九年到一九七九年，城乡之间的人口流动基本终止。那时，农村户籍的年轻人如果能被城市“招工”，常被形容为“鲤鱼跳龙门”。

为什么一次招工会有这么大的分量？因为在资源短缺的年代，获得城市户籍，不只是换一个居住地点，还意味着进入资源相对更多的城市分配体系。地点、身份和利益，被紧紧绑在了一起。

改革开放以后，第一道门松动了。城乡之间的人口可以自由流动，越来越多人进入城市工作。但第二道门，也就是身份与资源转换的门，并没有以同样的速度打开。

作者援引清华大学经济社会数据中心组织的全国城乡 PPS 抽样调查指出，农村户籍人口真正转变为城镇户籍人口的比例仍然很低，占全国总人口的百分之二十七点六；在二十年时间里，“农转非”的比例只有百分之七点七。

这里最值得注意的，不只是两个百分比，而是它们揭示出的速度差：劳动力进入城市可以很快，身份制度和资源格局的变化却慢得多。于是就出现了一个看似矛盾的现象——城市里有大量来自农村的劳动者，但“在城市工作”和“成为市民”仍然不是一回事。

当然，这并不意味着城乡关系永远不会改变。作者也提到，户籍制度改革一直在推进，建立淡化城乡分野的居民制度也是努力方向。需要警惕的是另一种过度简化：不能因为人口已经能够流动，就认为城乡差别会自动消失。

现在我们可以回答开头的问题了。

城乡分野之所以顽固，是因为它从来不只是一张户口簿造成的。它背后叠加着延续已久的资源配置差异、后来进一步固化身份的制度安排，以及现实中相对缓慢的市民身份转换。

城门可以打开，人也可以进城。但从跨过地理上的门，到跨过身份和资源上的门，中间仍然隔着很长一段路。这正是理解中国城乡分层问题时，最不能忽略的一层。

## 7. 验收标准

### 提示词

- 四个模板只使用当前系统开放的占位符；
- 必要占位符全部保留；
- 各阶段职责没有相互覆盖或冲突；
- 风格要求是可执行动作，而不是“有趣、通俗”等抽象形容词；
- 不要求模型模仿特定创作者。

### 样稿

- 所有事实来自两个指定原文块；
- 关键历史节点、调查数据和引用没有改变原意；
- 开场先建立认知缺口，不从定义开始；
- 主体采用“历史底层结构—制度加固—当代余波”的连续因果路线；
- 使用“城墙、门和锁”作为解释模型，但明确其为帮助理解的比喻；
- 结尾回扣“进城不等于完成市民身份转换”的开篇问题。
