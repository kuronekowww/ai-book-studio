# 六阶段内容生产提示词工作台设计

## 背景

当前“提示词”页面只把专辑大纲、声音细纲、声音初稿和声音终稿作为正式可配置环节。
专辑规划后来升级为分层流程后，“专辑大纲”编辑器实际上只控制分模块展开；前置的
思维导图和全书知识模块设计仍使用内部固定提示词。页面没有清楚展示每个模型调用的
真实输入，用户容易误以为专辑大纲没有收到拆书稿。

本次改造把六个内容生产环节升级为独立、版本化、可预览的用户提示词，同时继续保护
系统角色、输出格式、结构校验和自动纠偏等内部规则。

## 目标

1. 在左侧“提示词”页提供六个独立提示词编辑区。
2. 通过语义明确的占位符展示每个生产环节的真实输入链。
3. 项目级预览能够查看实际填充的拆书稿、上一步结果和来源材料。
4. 声音细纲只使用当前声音框架与所属模块拆书稿。
5. 声音初稿和终稿继续使用段落级原文块，保留精确溯源能力。
6. 提示词版本、项目覆盖、任务锁定、刷新恢复和历史版本规则保持一致。

## 非目标

- 不开放系统角色、JSON 转换、结构校验、来源匹配、集数纠偏或字数纠偏提示词。
- 不为“全书知识模块设计”和“分模块专辑大纲”新增独立模型选择；两者继续共用项目的
  “专辑大纲模型”。
- 不把真实拆书稿正文写入提示词版本。
- 不改变现有全局默认与项目级覆盖的继承规则。

## 六个正式提示词环节

| 阶段键 | 页面名称 | 使用模型 |
|---|---|---|
| `mind_map` | 思维导图 | 项目的思维导图模型 |
| `album_module_plan` | 全书知识模块设计 | 项目的专辑大纲模型 |
| `album_outline` | 分模块专辑大纲 | 项目的专辑大纲模型 |
| `episode_outline` | 声音细纲 | 项目的声音细纲模型 |
| `episode_draft` | 声音初稿 | 项目的声音初稿模型 |
| `episode_final` | 声音终稿 | 项目的声音终稿模型 |

每个环节拥有独立的系统版本、全局用户版本、项目覆盖版本和历史版本。项目生成任务
启动时锁定前三个提示词版本；单条声音和整张专辑生产任务启动时锁定后三个版本。

## 输入材料分层

### 思维导图

输入为完整拆书稿；超过模型输入预算时使用现有压缩流程生成的全书压缩拆书稿。压缩稿
仍须保留章节归属、概念、观点、关键论据、案例和金句。

必要占位符：

- `{{full_book_analysis}}`

### 全书知识模块设计

输入为覆盖全部一级章节的“策划版全书拆书稿”，以及全书轻量章节目录。策划版拆书稿
保留章节标题、章节主题、子主题、主要观点和一级章节标识，省略长论据、案例证据原文、
段落索引和知识资产 ID。这样既保持全书覆盖，又控制模型输入规模。

必要占位符：

- `{{planning_book_analysis}}`
- `{{chapter_catalog}}`

可选占位符包括书名、作者、书籍类型、专辑特殊要求、目标集数和每集字数范围。

### 分模块专辑大纲

每次模型调用只处理一个知识模块，输入当前模块说明和该模块涉及章节的详细拆书稿。
详细拆书稿保留模块策划所需的概念、观点、论据、案例和金句，但不要求模型输出段落级
索引或知识资产 ID。

必要占位符：

- `{{module_brief}}`
- `{{module_book_analysis}}`

### 声音细纲

输入严格限制为两类创作材料：

- 已确认专辑大纲中的当前声音框架；
- 当前声音所属模块的详细拆书稿快照。

段落级原文块、来源匹配结果和上一集终稿不进入声音细纲提示词。

必要占位符：

- `{{episode_framework}}`
- `{{module_book_analysis}}`

### 声音初稿

输入为声音细纲和当前声音匹配到的段落级原文块。来源匹配仍在声音工作流中执行，用于
保证初稿事实可溯源。

必要占位符：

- `{{episode_outline}}`
- `{{source_text}}`

### 声音终稿

输入为声音初稿和同一声音匹配到的段落级原文块。终稿只能调整表达、结构和听觉节奏，
不能借原文增加初稿没有覆盖的新事实段落。

必要占位符：

- `{{episode_draft}}`
- `{{source_text}}`

## 兼容占位符

为避免旧历史版本无法恢复，以下占位符继续允许使用，但在页面标记“旧版兼容”：

| 旧占位符 | 新含义 |
|---|---|
| 专辑阶段的 `{{book_analysis}}` | 当前环节对应的全书或模块拆书材料 |
| `{{module_source}}` | `{{module_book_analysis}}` |
| 声音细纲的 `{{source_text}}` | `{{module_book_analysis}}`，不是段落级原文 |

新建系统默认版本只使用语义明确的新占位符。旧别名映射到同一份材料，不会给模型增加
第三类声音细纲输入。

## 模块与声音的稳定关联

### 新项目

专辑规划时为每个模块保存不可变的模块输入快照，至少包含：

- `planning_run_id`
- `module_key`
- 模块位置与标题
- 来源一级章节 ID
- 模块详细拆书稿
- 创建时间

结构化专辑大纲必须为每条声音保留所属 `module_key`。保存声音时新增
`planning_run_id` 与 `module_key`，声音细纲通过这两个字段读取确切模块快照，不通过
标题、顺序或章节名称猜测。

### 历史项目

旧声音没有模块关联时，系统按其来源一级章节与最近一次成功专辑规划产物进行匹配：

1. 只有一个模块能够覆盖该声音全部来源章节时，建立恢复关联；
2. 没有可复用规划产物时，按声音来源章节生成恢复型模块拆书稿快照；
3. 多个模块都可能匹配且无法唯一确定时，不静默选择，声音任务提示重新生成专辑大纲
   后再继续生产。

恢复型快照必须标记来源，方便页面和运行记录区分“原始策划快照”与“历史恢复快照”。

## 提示词页面

### 环节导航

提示词工作台左栏按生产顺序显示六个环节。每项显示当前生效来源、系统版本，以及项目
覆盖状态。

### 编辑区

编辑区继续只允许修改用户提示词模板。顶部增加“本环节实际输入”摘要，明确展示：

- 上一步结果；
- 拆书稿层级；
- 是否使用段落级原文；
- 当前环节使用的模型配置名称；
- 必要占位符。

右栏占位符按钮保持可点击插入，必要占位符使用明确标识。缺少必要占位符、使用未知
占位符、花括号不完整或超过长度限制时禁止保存。

### 项目级真实预览

- 思维导图与全书知识模块设计：选择项目后直接预览。
- 分模块专辑大纲：选择项目后，再选择一个知识模块。
- 声音细纲、初稿和终稿：选择项目后，再选择一条声音。
- 全局范围使用示例材料，项目范围使用当前项目真实材料。

预览返回输入清单和渲染结果。每份长材料显示名称、来源、字符数、压缩状态和内容；
正文默认折叠，但允许展开完整查看。真实材料只用于本地预览，不写入提示词版本。

系统追加的保护约束继续放在只读折叠区。

## 工作流改造

### 项目生成

项目生成任务创建时锁定 `mind_map`、`album_module_plan` 和 `album_outline` 三个版本。

1. 准备完整或压缩拆书稿。
2. 构建覆盖全书的策划版拆书稿和章节目录。
3. 使用 `mind_map` 快照生成思维导图。
4. 使用 `album_module_plan` 快照生成全书知识模块。
5. 为每个模块保存模块拆书稿输入快照。
6. 使用 `album_outline` 快照并行生成各模块专辑大纲。
7. 结构化时保留 `module_key`，再保存声音。

单模块重跑继续使用顶层任务锁定的分模块提示词版本和既有模块输入快照。

### 声音生产

来源匹配阶段继续存在，但阶段结果不进入声音细纲：

1. 根据声音来源章节匹配段落级知识资产与原文块；
2. 声音细纲使用声音框架与模块拆书稿快照；
3. 声音初稿使用声音细纲与匹配原文块；
4. 声音终稿使用声音初稿与匹配原文块。

阶段上下文组装必须按环节区分变量，不能用一个通用 `source_text` 同时代表模块拆书稿
和段落级原文。

## 错误与恢复

- 思维导图缺少拆书稿时只让思维导图阶段失败，不阻断可独立继续的专辑规划。
- 全书知识模块设计缺少策划版拆书稿时停止专辑大纲流程，并显示明确错误。
- 单个模块缺少输入快照时只标记该模块失败，其他模块继续。
- 声音细纲找不到唯一模块快照时只让该声音失败，整张专辑批次继续。
- 提示词预览缺少项目、模块或声音选择时返回可操作的提示，不使用虚构数据代替。
- 恢复任务始终使用启动时锁定的提示词版本和模块输入快照。

## 数据迁移

数据库通过现有幂等迁移机制增加声音模块关联字段。模块输入快照优先复用现有
`album_planning_artifacts` 表，以 `artifact_type="module_source"`、对应 `module_key`
和 `planning_run_id` 保存，不复制到每条声音。

旧数据库初始化后不批量猜测模块关系；在预览或声音生产需要时执行可验证的惰性恢复。

## 测试与验收

### 后端

- 六个模板的初始化、版本、继承、恢复、校验和任务锁定。
- 新旧占位符映射和必要占位符校验。
- 三类拆书稿的构建、压缩标记和项目真实预览。
- 项目任务分别使用三个提示词快照。
- 模块输入快照与声音 `module_key` 的稳定关联。
- 单模块重跑复用原提示词版本与模块输入。
- 声音细纲不包含段落级原文。
- 初稿和终稿仍包含匹配原文。
- 历史声音唯一恢复、恢复型快照和歧义失败。
- 服务重启后的任务恢复和批量失败隔离。

### 前端

- 六项提示词导航和正确标签。
- 每个环节的输入摘要与必要占位符。
- 项目、模块和声音选择器。
- 真实素材清单、压缩状态、字符数和完整展开。
- 保存校验、版本历史、恢复和未保存离开提醒。
- 响应式布局和现有提示词页面功能回归。

### 验收标准

1. 用户能在一个页面独立编辑六个生产环节的用户提示词。
2. 项目级预览能证明专辑策划确实收到拆书稿。
3. 声音细纲预览只出现声音框架与模块拆书稿。
4. 声音初稿和终稿预览继续出现段落级原文。
5. 修改提示词后只影响新任务，运行中任务输出不漂移。
6. 既有项目不会因升级直接丢失提示词版本或声音内容。
