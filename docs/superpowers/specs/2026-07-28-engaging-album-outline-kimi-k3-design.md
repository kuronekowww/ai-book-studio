# 专辑大纲选题增强与 Kimi K3 专用模型设计

## 背景

现有专辑大纲能够覆盖拆书稿并保留知识资产和原文索引，但选题表达偏向知识点罗列，标题、核心主题和主要内容缺少问题意识、冲突感与连续收听动力。

本次调整只影响专辑大纲生成。拆书、思维导图、声音细纲、声音初稿和声音终稿仍使用用户选择的全局模型。

## 目标

1. 专辑大纲固定使用模型预设 `kimi-k3`。
2. 生成结果以听众关心的问题为中心组织，而不是机械复述章节目录。
3. 标题灵活使用问题、冲突、悬念、反常识、因果追问等表达方式。
4. 每集包含明确的核心主题和递进的核心要点。
5. 全部内容继续来源于逐章结构化拆书稿，并保留知识资产 ID 与原文索引。
6. 用户输入的期望集数和专辑特殊要求继续拥有最高优先级。

## 非目标

- 不增加第二次“标题润色”模型调用。
- 不修改全局模型选择。
- 不改变思维导图生成模型。
- 不更改专辑大纲审核页的核心数据结构。
- 不允许为了吸引力引入拆书稿之外的事实、观点或案例。

## 模型路由

工作流为不同任务分别获取模型提供者：

- 思维导图：继续使用当前全局模型。
- 专辑大纲：通过模型目录获取 `kimi-k3` 对应的提供者。
- 其他任务：保持现有模型选择逻辑。

如果 `kimi-k3` 配置不可用，专辑大纲任务明确失败并显示模型配置错误，不静默回退到其他模型。这样可以保证用户指定的模型约束可观察、可验证。

思维导图与专辑大纲仍可并行执行，但二者可以使用不同的模型提供者。

## 专辑组稿方法

提示词要求模型在输出前完成以下内部规划，但不输出分析过程：

1. 识别全书的核心问题、知识主线和读者最关心的现实问题。
2. 按内容关系组合拆书稿，而不是默认一章对应一集。
3. 为每集选择一个能够独立成立的核心问题。
4. 设计全专辑的收听顺序，使内容形成“发现现象—追问原因—解释机制—讨论影响或出路”的递进关系。
5. 再将每集绑定到实际使用的知识资产和原文索引。

内容足够且逻辑相关时，可以合并相邻章节或子主题；不得合并无关知识模块，也不得为了凑集数重复同一观点。

## 标题要求

标题优先使用以下方式，但不强制所有标题采用同一形式：

- 反常识或异常现象；
- 直接提出听众想知道的问题；
- 呈现两个力量之间的冲突；
- 揭示一个机制、误区或隐秘影响；
- 使用具体人物、现象、案例或概念作为入口。

标题需要准确反映拆书稿内容，避免：

- “第一章解读”“核心概念介绍”等目录式标题；
- “震惊”“颠覆认知”等空泛标题党；
- 把模型推断包装成原书结论；
- 多集使用高度重复的句式。

## 单集内容结构

保持现有 JSON 字段：

```json
{
  "title": "声音标题",
  "main_points": "核心主题：……\n核心要点：1. ……；2. ……；3. ……",
  "section_identifier": "章节与子主题说明，包含原文索引",
  "knowledge_item_ids": ["knowledge_xxx"],
  "content_type": "解读类"
}
```

字段要求：

- `title`：简洁、具体、有收听吸引力，并忠于拆书稿。
- `main_points`：
  - `核心主题`用一句话说明本集要解决的问题或揭示的机制；
  - `核心要点`通常为三个递进要点，可根据实际内容使用两至四个；
  - 要点优先覆盖“具体现象或故事—解释机制—现实影响或启示”，不机械套模板。
- `section_identifier`：保留人类可读的章节、子主题说明和精确 `content_index`。
- `knowledge_item_ids`：只列出本集实际采用的知识资产。
- `content_type`：保持现有解读类、过渡类约束；仅在确有必要时生成过渡类。

后端继续以知识资产来源表为准校正原文索引，避免模型返回的索引与资产实际来源不一致。

## 用户要求的优先级

提示词按以下优先级处理约束：

1. 事实必须来自拆书稿，引用必须可追溯；
2. 用户填写的专辑特殊要求；
3. 用户填写的期望集数；
4. 本设计中的选题与表达原则；
5. 模型根据内容密度自行判断的组稿策略。

如果用户未填写期望集数，模型根据知识模块数量与单集内容完整度决定，不设置固定下限。

## 错误处理

- `kimi-k3` 不存在或无法初始化：专辑大纲任务失败，思维导图不受影响。
- 模型输出不是有效 JSON：沿用现有结构化输出错误处理。
- 输出缺少标题、核心主题、核心要点、知识资产或索引：校验失败并保留可重跑状态。
- 输出引用不存在的知识资产：校验失败。
- 模型索引与知识资产来源不一致：后端使用资产的权威来源索引进行校正，并返回校正提示。

## 测试

### 提示词测试

- 包含问题导向、内容递进、标题多样性和禁止标题党的要求。
- 包含核心主题与核心要点的输出规范。
- 保留知识资产 ID、原文索引、集数和特殊要求约束。

### 模型路由测试

- 全局模型不是 `kimi-k3` 时，专辑大纲仍调用 `kimi-k3`。
- 同一次生成中的思维导图仍调用当前全局模型。
- `kimi-k3` 不可用时，只将专辑大纲标记为失败。

### 工作流测试

- 有效结果可保存为声音列表。
- `main_points` 包含核心主题和核心要点。
- 来源资产和原文索引完整保留。
- 用户指定集数与特殊要求被传入提示词。

## 验收标准

1. 在全局模型选择其他模型时生成专辑大纲，实际调用的仍是 `kimi-k3`。
2. 思维导图仍使用全局模型。
3. 新生成的每集都有具体、有吸引力且忠于原书的标题。
4. 每集主要内容明确区分核心主题与核心要点。
5. 相邻单集形成可理解的内容递进，而不是简单复制章节顺序。
6. 每集都保留有效的知识资产 ID 和原文索引。
7. 现有前后端测试通过，并新增专用模型路由与提示词测试。
