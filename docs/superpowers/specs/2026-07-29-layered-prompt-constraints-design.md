# 四阶段提示词分层约束设计

## 1. 目标

将示例字幕中“有趣、循序渐进、通俗易懂、信息密度高”的教学型叙事方法，与用户补充的细纲结构、观点标准、文稿结构、案例叙述和来源安全要求合并为一套可稳定批量执行的四阶段提示词。

听众默认此前没有读过原书，将主要通过连续收听获取书中内容。

## 2. 约束优先级

模型必须按以下优先级执行。低层要求不得破坏高层要求。

### 第一层：事实与范围安全

1. 只能使用当前声音框架、传入的原文块和上一步产物。
2. 不得使用模型自身知识补充新闻、书籍、数据、人物经历或案例。
3. 新闻只有已经包含在输入原文中时才能使用。
4. “新颖、有锐度”只能来自对输入内容的重新组织、对比和深入解释，不能创造原书没有的新事实或新结论。
5. 原文没有金句时不强行引用，直接总结，禁止编造金句。

### 第二层：声音框架与细纲结构

1. 当前声音框架决定本集范围，禁止跨出框架自由发挥。
2. 细纲必须输出声音主题、开篇、正文部分、跨模块过渡句和结尾。
3. 每个观点必须有输入材料中的论据支撑。
4. 案例最多两个，只能使用原文已有案例、事件或数据。
5. 初稿和终稿必须遵守细纲中的观点顺序。
6. 细纲的预告、跨模块过渡句和结尾是锁定句，初稿与终稿逐字使用，不得扩写或改写。

“跨模块过渡句锁定”只约束正文大模块之间的连接。模块内部仍可使用必要的因果连接语，否则无法形成自然口播。

### 第三层：听众理解

1. 先事实，后解释，再深入讨论。
2. 第一次出现的概念、数据、人物和专有名词必须解释其含义及其与本集问题的关系。
3. 清晰说明因果关系。
4. 每约 500 字交付一至两个核心认知点，避免连续堆叠新概念。
5. 数据不能裸报；必须解释比较对象、量级或它意味着什么，但不得加入原文没有的统计解释。

### 第四层：表达与趣味

1. 轻松、幽默、有趣、有料，但不说教。
2. 使用短句、提问式引导、生活化类比、适当对比和情绪共鸣。
3. 幽默、网络表达和流行梗只作为可选调味，不得影响准确性，也不得复制特定创作者的口头禅。
4. 案例的画面感只能来自原文已有细节。原文细节不足时，不得补写人物动作、心理、对话或环境。
5. 核心观点可以用不同角度重申，但不得机械重复同一句话。

### 第五层：归因

1. 默认直接讲事实、调查结果和逻辑。
2. 调查写成“某机构或某项调查显示……”，直接说明结果。
3. 只有作者亲身经历、直接引语、争议观点或必须区分不同立场时才说明归属。
4. 必须提及同一人物时，全文保持同一种常用称呼。

## 3. 四阶段职责

| 阶段 | 主要职责 | 不承担的职责 |
| --- | --- | --- |
| 专辑大纲 | 规划全书认知路线、单集核心问题、反差入口和来源资产 | 不写完整口播，不补原文外背景 |
| 声音细纲 | 设计单集认知任务、观点论据、案例职责、锁定句和难度梯度 | 不写长段正文，不制造案例细节 |
| 声音初稿 | 严格按细纲顺序完成深度解读，把事实和机制讲透 | 不改变锁定句，不增补新知识 |
| 声音终稿 | 优化听觉节奏、句长、指代和口语感 | 不重构观点顺序，不新增事实 |

3. 核心要点必须递进，不能只是并列摘要。
4. 优先选择能形成因果链的观点和案例。
5. 不单独生成泛泛导入、作者生平或内容总结，除非它是理解全书不可替代的背景。
6. 不把“作者认为”“书中指出”反复写进单集框架；观点归属影响理解时才列出姓名。

# 讲述气质
轻松但克制，清楚而有推动力。可以使用具体情境、反差和轻微幽默降低理解压力，但不得堆梗、滥用网络热词、模仿特定创作者或为了戏剧性夸大原书。

## 5. “城乡分野为何如此顽固”声音细纲

# 声音主题

- 本集核心问题：为什么人口已经可以进入城市，城乡之间的身份与资源边界仍然难以消失？
- 听众最终判断：现代户籍制度不是城乡差异的起点，而是在长期资源分化基础上的强力加固；人口流动加快，也不等于身份和资源转换同步完成。

## 开篇

- 预告：为什么人已经进了城，却不一定真正成为城市人？这期我们从古代的城墙讲到现代的户籍和市民身份，看看一条延续很久的资源边界，是怎样一步步被制度固化下来的。

## 第一部分：户籍制度不是城乡差异的起点

- 背景：古代“国人”指城市居民，“野人”指城外和乡下居民；城墙和夜间关闭的城门构成真实的空间边界。
- 主要观点：城乡分野的历史远早于现代户籍制度，本质上还包括资源与利益分配的不平衡。
- 论据：城墙不仅区分城里和乡下，也保护城里人的利益；费正清用“两个中国”概括农民社会与城市上层之间的长期差异。
- 案例（解释机制）：夜晚城门关闭后，城乡流动被完全阻断。只保留原文已有的城墙、城门和流动中断细节。
- 本部分核心认知点：城乡差异首先是一条长期存在的空间、资源和利益边界。

## 过渡句

- 如果说古代城墙划出的是空间边界，那么现代户籍制度锁住的，就是身份和资源的边界。

## 第二部分：户籍制度如何把差异变成身份

- 背景：二十世纪五十年代中后期，严格户籍制度建立。
- 主要观点：户籍制度没有创造城乡分野，却显著固化了既有差异，让居住地点、身份和资源获取被绑定在一起。
- 论据：从一九五九年到一九七九年，城乡人口流动基本终止；城市户籍意味着能够进入资源相对更多的城市分配体系。
- 案例（展示结果）：农村年轻人把被城市“招工”称作“鲤鱼跳龙门”，因为改变的不只是工作地点，还有身份和资源机会。
- 本部分核心认知点：户籍像是在原有城乡边界上加了一把锁，把资源差异固定为身份差异。

## 过渡句

- 但门打开，并不等于门槛消失；人口开始流动之后，真正难改变的东西才显了出来。

## 第三部分：能进城，为什么还不等于成为市民

- 主要观点：改革开放后人口流动恢复，但身份和资源转换明显慢于劳动力流动。
- 论据：两亿多在城市、城镇工作的农民工没有真正完成市民身份转换；全国城乡 PPS 抽样调查显示，农村户籍人口真正转为城镇户籍人口的比例仍然很低，占全国总人口的百分之二十七点六，二十年间“农转非”的比例只有百分之七点七。
- 数据解释：数字揭示的是速度差——人进入城市可以较快，身份制度和资源格局变化得更慢。
- 本部分核心认知点：“在城市工作”和“成为市民”是两种不同层次的流动。

## 结尾

- 费正清说：“自古以来就有两个中国。”城乡分野真正难跨越的，从来不只是地理距离，而是身份背后的资源距离。

## 6. 口播终稿

为什么人已经进了城，却不一定真正成为城市人？这期我们从古代的城墙讲到现代的户籍和市民身份，看看一条延续很久的资源边界，是怎样一步步被制度固化下来的。

很多人会把城乡差异的起点，直接放在二十世纪五十年代建立的户籍制度上。这个判断不能说完全错，但它只看到了离我们最近的一层。

中国的城乡差异远比现代户籍制度更古老。古代有所谓“国人”和“野人”的区分。“国人”住在城里，“野人”住在城外和乡下。

这不只是一套称呼。当时的城墙是一条真实存在的边界。白天，城门打开，人还可以往来；到了晚上，城门一关，城乡流动也就被切断了。

城墙当然有防御作用，但它同时保护着城里人的利益。换句话说，城乡分野从一开始就不只是住在哪里的问题。它还关系到资源集中在哪里，哪些人更靠近资源，哪些人更容易被排除在外。

费正清曾用“两个中国”来概括这种结构：一边是人数众多、相对稳定的农民社会；另一边是城市和市镇中更为流动的上层，那里聚集着地主、文人、商人和官吏。

这里说的“两个中国”，当然不是两个国家。它描述的是两套差异很大的生活和资源体系。

如果说古代城墙划出的是空间边界，那么现代户籍制度锁住的，就是身份和资源的边界。

从二十世纪五十年代中后期开始，严格户籍制度建立，城乡之间原本就存在的差异被进一步固化。从一九五九年到一九七九年，城乡人口流动基本终止。

那时，农村户籍的年轻人如果能被城市“招工”，常被形容为“鲤鱼跳龙门”。

为什么一次招工会有这么大的分量？

因为在资源短缺的年代，获得城市户籍，不只是换一个工作地点，也意味着可以进入资源相对更多的城市分配体系。地点、身份和利益，就这样被紧紧绑在了一起。

所以，户籍制度并不是凭空创造了城乡差异。它更像是在一扇已经存在很久的门上，又加了一把很结实的锁。

但门打开，并不等于门槛消失；人口开始流动之后，真正难改变的东西才显了出来。

改革开放以后，城乡之间的人口可以自由流动，越来越多人进入城市工作。第一道门松动了。

但第二道门，也就是身份和资源转换的门，并没有以同样的速度打开。当时有两亿多农民工在城市、城镇工作，却没有真正完成“市民身份”的转换。

清华大学经济社会数据中心组织的一项全国城乡 PPS 抽样调查显示，农村户籍人口真正转变为城镇户籍人口的比例仍然很低，占全国总人口的百分之二十七点六；在二十年时间里，“农转非”的比例只有百分之七点七。

这两个数字真正揭示的，是一种速度差。劳动力进入城市可以很快，身份制度和资源格局却变化得更慢。

于是，一个看似矛盾的现象出现了：城市里有大量来自农村的劳动者，但“在城市工作”和“成为市民”，仍然不是一回事。

这也是为什么，不能因为人口已经能够流动，就认为城乡差别会自动消失。户籍制度改革可以推动变化，但延续很久的资源格局和身份差异，很难在短时间里同时松动。

费正清说：“自古以来就有两个中国。”城乡分野真正难跨越的，从来不只是地理距离，而是身份背后的资源距离。
