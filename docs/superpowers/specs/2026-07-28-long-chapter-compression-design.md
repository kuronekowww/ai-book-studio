# 长章节拆书稿分段压缩设计

## 背景

《当代中国社会分层》的完整拆书稿超过全书直接输入阈值，生成专辑大纲前会逐章压缩。当前实现把每个一级章节的完整拆书稿交给模型一次性压缩。部分章节超过一万字符，`doubao-seed-2.0-pro` 在约 6300 字符处以 `finish_reason=length` 截断，导致生成大纲接口返回 500，项目保持零条声音。

## 目标

- 长章节压缩不再因单次输出上限导致整个专辑生成失败。
- 每个 `content_index` 和 `knowledge_item_id` 在压缩前后完整一致。
- 专辑大纲输入按原书顺序覆盖全部一级章节；每条声音同时携带知识资产 ID 和原文索引。
- 任何分段失败时不缓存半成品。
- 已成功缓存的章节继续复用，避免重复模型调用。
- 后端返回可读的 400 错误，不再把模型生成问题暴露为 500。

## 方案

### Markdown 分段

当完整逐章拆书稿超过 100000 字符时，先从上一步结构化拆书结果生成紧凑知识资产目录。目录按原书章节和子主题顺序保留：

- 章节标题与章节主题；
- 概念、金句、主要观点和案例的核心内容；
- 每项内容的 `knowledge_item_id`；
- 每项内容对应的全部 `content_index`。

逐条论据和案例证据全文仍完整保存在拆书稿与知识资产库中，单集组稿时按索引回取；全书编排阶段不重复输入这些支撑细节。这样使用的是上一步生成的拆书稿知识结构，而不是原书正文。

若紧凑目录仍超过 100000 字符，再按空行分隔的 Markdown 内容块切分并调用模型压缩。在不超过目标字符数的前提下顺序合并。超长单块按行切分；仍超长时才按字符安全切分。分段严格保持原始顺序，不修改文本和来源标识。

模型压缩的目标输入长度为 5000 字符。该值明显低于本次触发截断的章节长度，同时能够让模型在保留全部知识资产和来源标识的前提下完成输出。

### 自动拆小重试

每段调用现有 `chapter_compression` 提示词。若 provider 抛出 `ModelOutputTruncatedError`：

1. 将当前段按 Markdown 边界二分；
2. 分别压缩两个子段；
3. 子段仍截断时继续递归；
4. 达到最小段长度仍截断时，返回包含章节标题的可读失败信息。

只对明确的输出截断自动拆分；网关错误、超时和其他模型错误直接返回，不进行无意义重试。

若模型正常结束但遗漏或改写了来源标识，同样将当前片段继续拆小重试。达到最小片段后仍不完整才返回校验错误；网关错误和超时不触发该重试。

全书各章及章内分段共享一个并发限制器，最多同时进行 5 次压缩调用。模型返回顺序不影响结果顺序，最终仍按原书一级章节与章内片段的顺序合并。

### 来源完整性

每个叶子段分别比较压缩前后的：

- `content_index`
- `knowledge_item_id`

两类标识的集合必须完全一致。所有叶子段成功后，再对合并结果与整章原稿做一次全量比较。任何缺失、新增或改写都会阻止缓存。

### 专辑大纲来源契约

所有章节压缩稿按原书一级章节顺序合并后，同时输入思维导图和专辑大纲模型。专辑模型为每条声音输出：

- `title`：吸引听众点击的声音标题；
- `main_points`：按序号列出的每集主要内容、论据或案例；
- `section_identifier`：与参考格式一致的“章节 + 子主题 + 原文索引”；
- `knowledge_item_ids`：组稿使用的知识资产；
- `source_content_indexes`：后端根据以上知识资产生成的结构化段落级原文索引。

后端以知识资产来源表为权威数据，保留 `section_identifier` 中模型生成的章节/子主题文字，并用权威索引替换其中的原文索引，同时生成 `source_content_indexes`。项目详情和大纲审核页同时显示可读内容索引和精确原文索引。

思维导图和专辑大纲属于长输出任务，OpenAI 兼容 provider 分别设置 `max_tokens=16384` 和 `max_tokens=32768`；专辑大纲同时使用 JSON Object 响应格式。
思维导图和专辑大纲的请求超时分别为 600 秒和 900 秒，其他模型任务仍为 300 秒。
如果同一本书的思维导图已经成功保存而专辑大纲仍为空，重试时复用已有思维导图，只重新调用专辑大纲模型。
专辑模型一旦返回合法 JSON，后端在校验前保存带输入签名的草稿。相同书稿、提示词、模型和创作要求下重试时直接复用草稿；成功保存专辑后清除草稿。

### 缓存与错误

整章所有分段成功并通过校验后，才写入 `chapter_analyses.compressed_markdown`。生成专辑接口捕获 `ModelGenerationError`，以 HTTP 400 返回可读原因，页面沿用现有错误提示展示。

## 验收

- 模拟长输入在单次压缩会截断时，工作流自动分段并成功合并。
- 合并结果保留全部来源标识，顺序不乱。
- 某段缺少来源标识时，整章不写缓存并返回明确错误。
- 已缓存章节不重复压缩。
- 模型生成错误通过生成专辑接口返回 400。
- 后端测试、前端测试、lint 和生产构建通过。
- “专辑 1”使用《当代中国社会分层》真实生成出非空专辑大纲。
